## 💡 最佳实践

### 推荐做法 ✅

1. **探店视频首选活力探店装**
   ```markdown
   **角色**: 小洁 (预设服装：活力探店装)
   ```

2. **根据场景选择合适服装**
   - 高端餐厅 → 优雅约会装
   - 街头小吃 → 休闲街头装
   - 商务场合 → 职场通勤装

3. **保持服装一致性**
   - 同一视频中不要更换服装
   - 确保所有镜头的服装描述一致

### 不推荐做法 ❌

1. **混合多种风格**
   ```markdown
   ❌ 小洁 (上身丝绸吊带 + 下身骑行裤)  # 风格不搭
   ```

2. **过于复杂的描述**
   ```markdown
   ❌ 小洁穿着一件非常漂亮的、红色的、有蕾丝边的、
      从法国进口的、价值 1000 元的连衣裙...  # 过于冗长
   ```

3. **忽略场景适配**
   ```markdown
   ❌ 健身房场景穿优雅约会装  # 场景不匹配
   ```
