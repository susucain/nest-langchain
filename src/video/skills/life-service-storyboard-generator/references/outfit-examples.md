# 预设服装使用示例

> 📖 本文件展示了如何在分镜脚本中使用预设服装系统，快速指定穿着细节。

---

## 🎯 使用方式对比

### ❌ 传统方式（繁琐）

```markdown
**角色**: 小洁 (上身浅色紧身衣，下身瑜伽裤，干练形象)
```

每次都需要详细描述，容易遗漏细节，且不够标准化。

---

### ✅ 预设服装方式（简洁）

```markdown
**角色**: 小洁 (预设服装：活力探店装)
```

系统会自动展开为详细服装描述：

```

身材匀称干练，黑色长发扎成高马尾，脚穿白色运动鞋，
佩戴简约手表和小耳钉，充满活力与自信。
```

## 🔧 技术实现

### 预设服装展开流程

1. **识别预设名称**: 检测用户输入中的"(预设服装：XXX)"格式
2. **读取配置文件**: 从 `references/preset-outfits.md` 读取对应服装的完整描述
3. **替换展开**: 将预设名称替换为详细服装描述
4. **应用到分镜**: 将展开后的描述应用到所有镜头的画面描述中

### 代码逻辑（伪代码）

```python
def process_outfit_input(user_input):
    # 检测是否使用预设服装
    if "预设服装：" in user_input:
        outfit_name = extract_outfit_name(user_input)
        outfit_details = load_from_preset_file(outfit_name)
        return expand_outfit_description(outfit_details)
    else:
        # 使用默认或自定义描述
        return user_input
```

## ✅ 优势总结

使用预设服装系统的优势：

1. **快速指定**: 一个名称代替冗长描述
2. **标准化**: 确保服装描述的一致性和完整性
3. **细节丰富**: 自动包含上衣、裤子、鞋子、配饰、发型等完整细节
4. **易于扩展**: 可以随时添加新的预设服装
5. **减少错误**: 避免遗漏重要穿着细节
6. **提升效率**: 无需每次都重新描述服装
